# 简约模式设计规格

日期：2026-08-22
状态：已确认

## 目标

监控页默认使用简约布局，只保留判断当前额度与使用节奏所必需的信息；原来的全量细节作为可选的“极客模式”。独立的“协同建议”收进“协同时间线”卡片，并以“协同计划”呈现。

## 用户入口与状态

- 在“设置”页提供“极客模式”开关。默认关闭，主界面为简约模式。
- 打开极客模式后，监控页显示原来的全量细节（数据来源提示、5 小时窗口、实时流水、诊断信息）。
- 开关状态保存在现有浏览器本地偏好中；刷新页面、关闭再打开应用后保持不变。
- 开关只影响“监控”主页面，不影响“报告”“插件”“设置”和桌面托盘页。

## 简约模式下的主页面

正常有可见 Agent 时，主页面按以下顺序只显示：

1. “更紧的窗口”摘要。
2. “协同时间线”卡片，卡片内同时包含原“协同建议”的内容，并以“协同计划”作为内部分区标题。
3. 当前可见的 Agent 配额卡，顺序仍为 Claude Code、Grok、Codex；未检测到的 Agent 不显示。
4. “近 24 小时 token”图表，独占整行宽度。

简约模式中的 Agent 配额卡进一步收敛为周维度摘要：

- 保留卡头、套餐/适配器、状态与暂停/采集按钮。
- 主百分比和额度条统一显示本周额度；Claude 与 Codex 不再显示 5 小时窗口、燃烧率或预计耗尽。
- 数据统计显示四项：“本周已用 token”“本周用量”“本周预估总 token”“本周预估总用量”。“本周预估总 token”使用当前套餐的周 Token 预算；“本周预估总用量”复用现有整周 API 等价估算区间，无法可靠校准时显示“样本不足”。
- 除“本周预估总用量”外，隐藏卡头来源说明、额度条来源后缀、来源诊断、产品占用、模型专属周额度、credit 等价、其他金额区间、价格覆盖率、置信度、价格版本、实时会话、并行任务和模型拆分；额度条仅标为“本周额度”。
- Antigravity 不使用本地 token 套餐摘要：它的简约卡作为官方额度例外，分别显示“Gemini 模型”与“Claude / GPT 模型”两类剩余百分比；每类只显示本类 5 小时与每周窗口中更紧的一项，不展开四池明细。
- 极客模式继续显示现有窗口、周额度和全部详细数据。

以下极客模式内容在简约模式隐藏：

- 顶部数据来源提示条。
- 独立的“协同建议”卡片。
- “实时流水”卡片。

页面 Header、导航、主题切换、暂停/开始协同按钮继续保留；它们是全局操作入口，不属于被精简的内容板块。

## 协同计划合并规则

- 极客模式与简约模式都不再显示独立的“协同建议”卡片。
- 当存在可用建议时，在“协同时间线”的时间轴下方增加分隔线和“协同计划”区，复用现有建议生成结果与文案。
- “协同计划”标题与建议保持同一行；每条建议标题和正文单行截断，不在标题下方再堆一块空白卡片。
- 没有可用建议时，不显示空的“协同计划”区，也不为它预留空白。
- 合并只改变展示位置，不改变建议算法、Agent 启停逻辑、时间线的五小时窗口或事件数据。

## 响应式布局

- 桌面宽屏继续使用“更紧的窗口”左窄栏、“协同时间线”右宽栏；三张 Agent 卡同排。
- 中等宽度保持现有两列 Agent 卡布局。
- 手机窄屏按“更紧的窗口 → 协同时间线/计划 → Agent 卡 → 近 24 小时 token”单列排列，不出现横向滚动。
- “协同计划”标题与建议同一行，建议单行截断，不能横向撑破时间线现有的 Agent 标签列。

## 空态与失败场景

- 没有检测到任何 Agent 时，继续显示现有“未发现可监控 Agent”空态及“打开设置”入口；此状态优先于简约模式板块限制。
- 某些官方额度暂不可用时，沿用现有板块条件与降级文案，不伪造“更紧的窗口”数据。
- 本地存储不可用时，当前会话仍可切换模式；刷新后回到默认简约模式，不能导致页面崩溃。
- 旧版持久化数据没有简约/极客字段，或 persist version 为 0 时，按简约模式处理。

## 非目标

- 不改变额度计算、告警阈值、套餐选择、日志采集或协同建议算法。
- 不把设置页的套餐/告警 `PlansPanel` 搬到主页面。
- 不删除极客模式，也不改变报告、插件、设置、托盘页面内容。
- 不修改公共演示数据和现有 Agent 可见性判断。

## 验收标准

1. 新用户与旧版存储默认进入简约模式；设置页“极客模式”默认关闭，刷新后状态与页面布局保持。
2. 简约模式主页面只出现目标四类内容；提示条、独立建议卡和实时流水均不存在。
3. 极客模式仍显示提示条与实时流水，但“协同建议”已作为“协同计划”嵌入协同时间线，不再单独占卡。
4. 合并后的时间线仍能显示各 Agent lane，暂停/开始协同按钮仍可用。
5. 单 Agent、三 Agent、无 Agent 三种状态均符合现有可见性和空态规则。
6. 1280px 桌面与 390px 手机视口均无横向溢出；协同计划标题与建议同一行。
7. 单元测试、类型检查、构建及真实浏览器路径验收通过。
8. 简约模式下每张 Agent 卡依次显示“本周已用 token”“本周用量”“本周预估总 token”“本周预估总用量”四个统计项，且三张卡都没有 5 小时窗口信息；打开极客模式后原有详细数据恢复。
